BEYOND A CHAT WINDOW

A useful extra pair of hands.

Connect local intelligence to the tools you already use.

01 / SCREEN

See and act

Inspect screenshots and window controls. Click, type, scroll, drag, and use keyboard shortcuts in an approved target window.

02 / FILES

Build and fix projects

Switch to Coding agent, choose a project, and let Jarvis inspect source, edit files, run builds and tests, fix errors, and start local previews. Watch saved edits and streamed command output in the live workspace. Edits have backups; commands follow your approval setting.

03 / INTERNET

Stay current

Search the web and read pages with source links. Research queries go to search providers; model inference stays local.

04 / LOCAL AI

Your choice of model

Choose and load a downloaded tool-capable LM Studio model directly above the chat. Use a separate vision model for screenshots, or one that does both.

05 / VOICE

Talk it through

Dictate with Windows’ installed offline speech recognizer and listen to spoken replies. Review your message before sending.

06 / CONTROL

Keep the final say

Choose allowed folders, toggle capabilities, and stop a task. Use manual approvals or enable Auto-approve actions for uninterrupted work. PowerShell stays disabled until you enable it.

FIRST RUN

Three steps to a local assistant.

01

Prepare LM Studio

Install LM Studio, download a model with tool support, and start its local server on port 1234. Gemma 4 E4B is the default for chat and vision.

02

Open Jarvis

Extract the Windows ZIP into a folder and run Jarvis.exe. Use Settings to select your downloaded chat and vision models.

03

Start with a small task

Try “Check my PC’s memory usage.” Then inspect a test app or create a text file, reviewing each approval as you go.

GOOD TO KNOW

Before you hand
over a task.

Does the model run in the cloud?

Jarvis connects to LM Studio only on your own PC. It accepts downloaded local GGUF/MLX models listed by that server. Web search and page-reading tools contact the internet when enabled.

Can it control every app?

It can control visible windows on the primary screen with normal Windows user permissions. Elevated apps, games, minimized windows, and apps with limited accessibility may need manual help. Local models can make mistakes; review actions.

Does this website control my PC?

No. This is a download page. You need to install and run the local Jarvis app to use PC tools. The interactive example above is a demonstration only.

Where are my chats and screenshots stored?

The Windows build stores settings, chats, preferences, screenshots, activity, backups, and recovery files under your local application data folder in JarvisLocal. These files are local and unencrypted. The source version uses its data folder.

Is there an always-listening microphone?

No. Dictation starts when you click the microphone button and uses the installed Windows speech recognizer. There is no wake word or continuous recording.

Is it free?

The Jarvis app is free and MIT licensed. LM Studio and model licenses apply separately. This release has no account, subscription, or paid API requirement.
